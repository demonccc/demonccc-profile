# Professional Feedback

This directory preserves recommendations and testimonials received from people who worked with Claudio.

Feedback is external perspective, not proof of a technical capability. Capability claims belong in experience, projects and evidence; feedback can provide human context about leadership, collaboration, technical judgment and working style.

Rules:

- Preserve the original wording whenever the text is available.
- Record the relationship and professional context when known.
- Link back to the related experience when useful.
- Do not include skill endorsements, recruiter outreach, automated congratulations or recommendations written by Claudio about other people.
- Prefer the original public source link when one is available, while still preserving the recommendation text when possible.
