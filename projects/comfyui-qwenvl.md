# ComfyUI-QwenVL

## Overview & Motivation

Custom ComfyUI integration for running modern Qwen vision-language models inside node-based visual workflows, including memory-efficient model execution on consumer hardware.

## Architecture & Implementation

The node bridges ComfyUI with multimodal inference libraries and supports image/video inputs, Qwen2.5-VL and Qwen3-VL workflows, and memory-conscious execution including GGUF-based model variants where applicable.

## My Contribution

I created, designed and maintain the project, including the Python integration, workflow behavior and compatibility work required to run multimodal models inside ComfyUI.

## Key Capabilities Demonstrated

Multimodal model integration, Python extension development, GPU/VRAM constraints, model runtime engineering and workflow-oriented product design.
