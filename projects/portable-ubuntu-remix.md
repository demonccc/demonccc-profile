# Portable Ubuntu Remix

## Overview & Motivation

Portable Ubuntu Remix was created to run a complete Ubuntu environment on Windows without repartitioning the disk and without relying on a conventional full virtual machine.

## Architecture & Implementation

The system combined Cooperative Linux (CoLinux), Xming and PulseAudio for Windows so Linux applications could execute alongside Windows and expose graphical windows and audio to the host desktop.

## My Contribution

I created and led the project, integrated the components, packaged the distribution and maintained its public SourceForge release and community support.

## Key Capabilities Demonstrated

Low-level Linux/Windows integration, packaging, troubleshooting, open-source project ownership and pragmatic architecture under hardware constraints.

## Results & Lessons

The project reached a broad international user base and became one of my earliest public examples of building an end-to-end technical product rather than only operating infrastructure.
