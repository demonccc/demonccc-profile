# GUI for the Cisco VPN Client

## Overview & Motivation

The official Cisco VPN client for Linux had no practical graphical interface, forcing users to manage connection profiles and sessions from the command line.

## Architecture & Implementation

I built a Python/GTK front-end that discovered Cisco VPN profiles, exposed connection controls and managed the underlying client process and connection state.

## My Contribution

Creator, developer and maintainer of the project, including packaging and SourceForge publication.

## Results & Lessons

The project turned a command-line corporate connectivity tool into a simpler desktop workflow for Linux users.

- SourceForge: http://sourceforge.net/projects/guiforciscovpnc/

## Tech Stack

Python, GTK/PyGTK, Cisco VPN Client for Linux, Shell scripting and SourceForge.
