# Trayector Implementation

This career profile follows **Trayector v0.1**, an open implementation of **Career as Code**.

- Specification: https://github.com/demonccc/trayector
- Machine-readable entry point: [`profile.json`](profile.json)
- Profile-owned vocabulary: [`settings.yaml`](settings.yaml)

The repository README is intentionally a human-facing profile index. Trayector-specific modeling rules, templates and compatibility guidance live in the Trayector repository rather than being repeated in the profile view.

The canonical career knowledge lives in the linked profile, experience, project, deep-dive, story, feedback and content documents. `README.md` is a derived view of that knowledge and can evolve as the profile changes.
