## Mission & Context

Operated high-availability Linux infrastructure for a global communications platform, working with distributed engineering teams in India and the Netherlands.

## What I Actually Did

- Administered Debian/Linux servers, applications and network services in live environments.
- Worked with physical Dell PowerEdge infrastructure and AWS EC2 Classic.
- Supported critical distributed services including Ejabberd, Redis and MySQL.
- Implemented and supported infrastructure automation using tools such as Chef, Puppet and CFEngine.
- Integrated infrastructure inventory and operational tooling, including iTop.
- Designed and maintained CI/CD workflows with Jenkins.
- Worked on high-performance web infrastructure with Nginx, PHP-FPM, caching, WebSockets and early SPDY/HTTP2 experimentation.
- Built and operated monitoring and logging stacks using tools including Nagios, Zabbix, Sensu, OpenTSDB and Graylog.
- Supported distributed systems including RabbitMQ, Elasticsearch and Riak.
- Performed capacity planning, incident handling and Root Cause Analysis.
- Supported development teams with Git workflows, infrastructure issues and headless Selenium testing.

## Tech Stack & Methods

Debian/Linux, AWS EC2 Classic, Dell PowerEdge, Chef, Puppet, CFEngine, Jenkins, Nginx, PHP-FPM, Redis, MySQL, RabbitMQ, Elasticsearch, Riak, Nagios, Zabbix, Sensu, OpenTSDB, Graylog, LXC, Git, Selenium and RCA.
