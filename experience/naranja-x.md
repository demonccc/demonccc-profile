## Mission & Context

Engineering leadership and architecture role during Naranja X's fintech and cloud transformation. The scope combined cross-functional Cloud Chapter leadership with hands-on Cloud Solution Architecture across product tribes.

## What I Actually Did

- Led cloud strategy across business tribes and defined architecture, scalability, security and efficiency standards.
- Designed and implemented self-service modules for AWS and Azure through the local Internal Developer Portal.
- Standardized Infrastructure as Code and deployment pipelines, including CI workflows for Serverless applications.
- Directed the evolution of Infrastructure as Code from Terraform toward Pulumi for reusable, programmable components.
- Designed hybrid and multi-region architectures linking on-premise systems with cloud platforms.
- Participated in the design of Serverless and Event-Driven Architecture solutions using AWS Lambda, SQS and other messaging technologies.
- Co-led FinOps and cloud cost visibility practices using AWS Cost Explorer, Athena and PowerBI, including tagging strategy.
- Designed cloud observability and APM capabilities with Datadog, Fluent Bit and Telegraf and promoted APM for AWS Lambda.
- Led performance-engineering initiatives using production-like EKS sandboxes with mocked data.
- Mentored technical profiles and participated in technical recruitment and the transition toward the Spotify-inspired operating model.

## Tech Stack & Methods

AWS, Azure, EKS, Kubernetes, Lambda, SQS, Pulumi, Terraform, GitLab CI, Datadog, Fluent Bit, Telegraf, Athena, PowerBI, Serverless, Event-Driven Architecture, FinOps and Internal Developer Platforms.
